# Sistema de Gestión de Biblioteca 📚

Este proyecto implementa un sistema de gestión de biblioteca en Python, permitiendo a los usuarios **añadir libros**, **registrar usuarios**, **realizar préstamos y devoluciones**, y **consultar la disponibilidad de libros**. Se ha integrado una interfaz gráfica con **Gradio** para facilitar la interacción.

---

## 🚀 Características Principales
- 📖 **Añadir nuevos libros** con título, autor y género.
- 👥 **Registrar usuarios** para gestionar préstamos.
- 🔄 **Realizar y gestionar préstamos y devoluciones**.
- 📜 **Consultar la disponibilidad de los libros** en tiempo real.
- 🌐 **Interfaz gráfica con Gradio** para una experiencia intuitiva.

---

## 🏗️ Estructura del Proyecto
```
library_management/
│── app.py        # Interfaz gráfica con Gradio
│── main.py       # Módulo de pruebas
│── book.py       # Clase para la gestión de libros
│── genre.py      # Enumeración de géneros de libros
│── user.py       # Clase de gestión de usuarios
│── employee.py   # Clase de gestión de empleados
│── library.py    # Módulo principal de la biblioteca
└── README.md     # Documento de información del proyecto
```

---

## ⚙️ Instalación y Ejecución

### 🔹 1. Clonar el repositorio:
```bash
git clone https://github.com/usuario/library_management.git
cd library_management
```

### 🔹 2. Instalar dependencias:
Asegúrate de que tienes **Python** instalado, luego ejecuta:
```bash
pip install -r requirements.txt
```

### 🔹 3. Ejecutar la aplicación:
```bash
python app.py
```
La interfaz se abrirá en tu navegador mostrando las opciones para gestionar la biblioteca.

---

## 💻 Uso de la Aplicación
1. **Selecciona una acción** en el menú desplegable.
2. **Introduce los datos** según corresponda:
   - Para añadir un libro: título, autor y género.
   - Para registrar usuario: nombre.
   - Para prestar/devolver libros: nombre de usuario y título del libro.
3. **Haz clic en "Enviar"** para realizar la operación.
4. **Consulta la lista de libros** para ver su disponibilidad.
